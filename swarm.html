How the swarm
works.

The cursor-agent rebuild you just watched, explained with the real code. There are two different "swarms" here, and it matters which is which.

00

Two swarms

The real one ran on my machine while I was building this site: a fleet of AI agents read my project folders (read-only) and a second agent fact-checked the result. That is section 03 and 04.

The one you watched is a front-end effect. The twelve cursors are not AI. They are small scripted actors that pick a block, fly to it and flash a selection box. It is theatre, built to show the idea, and the code is in sections 01 and 02.

No libraries, no tracking. One JavaScript function and a few dozen lines of CSS. Your XP and badges live only in your own browser.

01

The effect

1. Pick the layers

Every headline, job, project, skill group and education item counts as a "layer", sorted top to bottom.

const layers = $$('.hero__title, .hero__role, .section__head, .job, .project, .skills__group, .edu__item, .facts > div, .contact__links li')
  .filter((el) => el.getBoundingClientRect().width > 0)
  .sort((x, y) => docTop(x) - docTop(y));

2. Each agent picks a layer and flies to it

Agent 0 is the lead: it takes the earliest unbuilt layer and the page scrolls to follow it. The other agents take whichever unbuilt layer is nearest to where the lead is working, which keeps the swarm on screen. Reduced-motion visitors get a calmer version (no flicker, no smooth scroll, shorter moves).

async function work(agent, idx) {
  while (!run.stop && todo.length) {
    // The lead agent takes the earliest unbuilt layer and the page follows it;
    // the others take whichever unbuilt layer is nearest to where the lead is working.
    let pick = 0;
    if (idx !== 0) {
      let best = Infinity;
      todo.forEach((t, i) => {
        const d = Math.abs(docTop(t) - run.focusY);
        if (d < best) { best = d; pick = i; }
      });
    }
    const el = todo.splice(pick, 1)[0];
    const r = el.getBoundingClientRect();
    if (idx === 0) {
      run.focusY = r.top + scrollY;
      window.scrollTo({ top: Math.max(0, run.focusY - innerHeight * 0.3), behavior: calm ? 'auto' : 'smooth' });
    }
    const x = Math.min(maxX(), Math.max(8, r.left + r.width * (0.2 + Math.random() * 0.6)));
    const y = r.top + scrollY + r.height * (0.15 + Math.random() * 0.7);
    agent.el.style.transitionDuration = ((calm ? 0.25 : 0.7) / run.speed) + 's';
    agent.el.style.transform = 'translate(' + x + 'px, ' + y + 'px)';
    await sleep(750 + Math.random() * 350);
    if (run.stop) break;
    build(el, agent.color);
    await sleep(300);
  }
}

3. "Build" the layer

A dashed box in the agent's colour is laid over the block with its size, the block flickers, then both disappear.

function build(el, color) {
  const r = el.getBoundingClientRect();
  const box = document.createElement('div');
  box.className = 'swarm-box';
  box.style.setProperty('--c', color);
  box.style.left = r.left + scrollX + 'px';
  box.style.top = r.top + scrollY + 'px';
  box.style.width = r.width + 'px';
  box.style.height = r.height + 'px';
  const tag = document.createElement('span');
  tag.textContent = Math.round(r.width) + ' × ' + Math.round(r.height);
  box.appendChild(tag);
  overlay.appendChild(box);
  el.classList.add('sw-building');
  setTimeout(() => { el.classList.remove('sw-building'); box.remove(); }, 650 / run.speed);
  run.done++;
  progress();
}

02

The triggers

Three ways in: the Konami code, asking the assistant for something cool, or switching the "View as" menu in the footer. The menu runs the same swarm, and at the halfway point the page content swaps to the new view (headline, project order, CV link, lab sections). A ?swarm=1 link also starts it.

The two chat phrases below are matched in your browser before any message is sent to the AI, so they work even when the AI is offline.

const COOL = /something cool|anything cool|(show|give|do|got).{0,20}(something|anything|stuff).{0,12}(cool|awesome|impressive|fun|wild|neat)|\b(wow|impress|surprise) me\b/i;

03

The real swarm

Phase 1: one read-only agent per project folder, then a synthesis agent and a fact-checking critic. Repo names are placeholders. The critic caught several over-claims, which is why employer work on this site is described as "contributor" and some projects are left out.

export const meta = {
  name: 'portfolio-project-discovery',
  description: 'Read-only scan of project folders + profile data to build a public-safe knowledge base',
  phases: [
    { title: 'Scan', detail: 'one read-only agent per project folder' },
    { title: 'Synthesize', detail: 'merge into knowledge base + critic pass' },
  ],
}

const BASE = '~/code/'
const REPOS = ['api', 'web-app', 'mobile-app', 'chatbot', 'saas-widget', 'tooling'] // placeholders

const SCAN = {
  type: 'object',
  properties: {
    folder: { type: 'string' }, exists: { type: 'boolean' },
    name: { type: 'string' }, oneLiner: { type: 'string' }, summary: { type: 'string' },
    stack: { type: 'array', items: { type: 'string' } },
    highlights: { type: 'array', items: { type: 'string' } },
    role: { type: 'string' },                    // what the git history says I did
    employerConfidential: { type: 'boolean' },
    publicSafeNotes: { type: 'string' },
  },
  required: ['folder', 'exists', 'name', 'oneLiner', 'summary', 'stack', 'highlights', 'employerConfidential', 'publicSafeNotes'],
}

phase('Scan')
const scans = await parallel(REPOS.map(r => () => agent(
  `READ-ONLY. Inspect "${BASE}${r}": README, manifests, layout, git log and shortlog.
   Never open .env or key files. Never output secrets, URLs, customer names or personal data.
   Describe only what the evidence shows. Judge whether it is proprietary and say what is safe to publish.`,
  { label: `scan:${r}`, phase: 'Scan', schema: SCAN, effort: 'low' }
)))
const found = scans.filter(Boolean).filter(s => s.exists)
log(`${found.length}/${REPOS.length} scanned`)

phase('Synthesize')
const kb = await agent(
  `Build the portfolio knowledge base from these scans and my master profile. Pick the strongest projects,
   describe employer work generically, and keep a "never claim" list. Accuracy over flattery.
   Scans: ${JSON.stringify(found)}`,
  { label: 'synthesize', phase: 'Synthesize', effort: 'high' }
)

// Adversarial pass: a second agent tries to refute the first.
const critic = await agent(
  `Fact-check this knowledge base against the scans. Flag anything unsupported, inflated, or leaking
   confidential detail, and give concrete fixes.\nKB: ${JSON.stringify(kb)}\nScans: ${JSON.stringify(found)}`,
  { label: 'critic', phase: 'Synthesize', effort: 'medium' }
)
return { kb, critic }

// Blueprint for the rebuild phase: what fans out across agents, and how it is checked.
// A sketch of the approach, not a log of one run.
export const meta = {
  name: 'portfolio-rebuild',
  description: 'Rebuild a static portfolio: design system, chatbot, gamification, verification',
  phases: [
    { title: 'Design', detail: 'one agent sets the Swiss design tokens and grid' },
    { title: 'Build', detail: 'parallel agents, each owning separate files' },
    { title: 'Verify', detail: 'browser tests + adversarial fact-check' },
  ],
}

phase('Design')
const tokens = await agent(
  'Define a Swiss/International-style system: 12-column grid, one typeface, one accent, light + dark tokens.',
  { label: 'design-tokens', phase: 'Design' }
)

phase('Build')
// Each agent owns different files, so no worktree isolation is needed.
const OWNERS = [
  { key: 'chat-api', files: 'netlify/functions/*', task: 'Server-side chat endpoint: key stays in env, input caps, rate limit, grounded system prompt.' },
  { key: 'chat-ui', files: 'chat panel in script.js + css', task: 'Accessible chat widget with suggested questions and an offline fallback.' },
  { key: 'gamify', files: 'xp / badges in script.js', task: 'XP, levels, badges, localStorage only, decorative and honest about it.' },
  { key: 'content', files: 'index.html', task: 'Projects and skills strictly from the fact-checked knowledge base.' },
]
const built = await parallel(OWNERS.map(o => () =>
  agent(`${o.task}\\nOnly edit: ${o.files}.\\nDesign tokens:\\n${tokens}`, { label: o.key, phase: 'Build' })))

phase('Verify')
const LENSES = ['keyboard + screen reader', 'mobile overflow', 'prompt-injection against the chatbot', 'claims vs evidence']
const verdicts = await parallel(LENSES.map(l => () =>
  agent(`Try to break the site through this lens: ${l}. Report only reproducible failures.`,
        { label: `verify:${l}`, phase: 'Verify', effort: 'high' })))
return { built, verdicts }
