What this site counts

To see how the site is used and whether it works, it counts a few things as plain numbers: which pages are opened, which view of the site (Data, Design, Shop, Classic), which website sent the visitor (the host name only), the country (two letters) and whether the screen is a phone, tablet or desktop; how fast pages load; errors in the page, with web addresses, e-mail addresses and long numbers removed; how long the heavier effects take; and how many tokens and seconds the chat assistant used.

It does not keep IP addresses, browser details, cookies, anything you type into the chat or the contact form, or anything that identifies you. Nothing is counted when your browser sends Do Not Track. The counts are stored in Netlify's own storage, 90 days at most, and only the owner can read them.
