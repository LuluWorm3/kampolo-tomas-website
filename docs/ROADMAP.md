## Risks

- **Time sink:** polish replaces applying. Mitigation: apply to roles in parallel; the personas exist to make applications easier, not to be finished.
- **Gimmick perception:** corporate readers may dislike effects. Mitigation: calm default, effects opt-in, "Classic" view.
- **Generated files drift:** persona pages, CV pages and PDFs are outputs. Edit sources (`index.html`, `personas.js`, `scripts/cv-data.mjs`, `scripts/documents.mjs`) and re-run `node scripts/build.mjs --pdf`.
- **Document exposure:** personal data in certificates and transcripts. Mitigation: redaction checklist in `scripts/documents.mjs`, consent for letters.
- **Over-claiming:** see the guardrails in `AGENTS.md`.
- **Chatbot abuse or cost:** capped input and output, per-instance rate limit, grounded prompt. Watch the Anthropic usage dashboard.

## Not doing

- A JavaScript framework or build pipeline for the whole site.
- Logged-in or gated documents.
- Publishing ID, date of birth, home address, student number, second phone, or reference contact details without consent.
- Autoplaying effects or sound.
- Any claim not backed by evidence.
